## Why

在上一次首頁 UI 改版實作完成後，經由實際畫面檢視與使用者回饋，發現首頁存在以下幾點精緻度不足的問題：
1. **公告看板重心塌陷**：中間公告看板 (`LotusWelcomeWidget`) 頂部與底部控制按鈕的垂直間距過大，導致下半部的公告內容與按鈕有垮下去的感覺。
2. **名片標籤撐爆溢出**：當左側姓名與右側遊戲標籤在同排且過長時，會產生擠壓並推出名片外右側，導致版面崩潰。
3. **發言框過高與標籤擁擠**：發言區 `min-h-[68px]` 偏大，導致在窄螢幕上底部的 tags 容易因空間不足折行跑版。
4. **缺乏頭貼與滑動動畫**：名片使用冷冰冰的首字貼紙替代頭像，且新卡片進來時是瞬間切換，缺乏流暢、高級的「大廳名片輸送帶」滑動過渡感。

本提案旨在精準修復這四項體驗痛點，全面提升 Morning Sketch 視覺精緻度。

## What Changes

- **中間看板重心對齊**：優化 `LotusWelcomeWidget.tsx` 垂直 flex 佈局，拉近蓮花與文字間距，使其向中間緊實居中，不再塌陷垮下。
- **發言框收窄與防溢出**：發言區縮小為固定 `h-[56px] min-h-[56px]`，字體調整為 `text-xs`。
- **名片大頭貼與標籤重排**：
  - 徹底移除首字貼紙。大頭貼改為套用 `avatar_url` 真實使用者頭貼（預設為超高品質的 Lorelei 日系手寫風肖像圖片，完美與 `profile` 設定的頭貼格式相容）。
  - 將 `game • hero` 標籤的字體縮小為 `text-[10px]` 並移至「姓名下方」，徹底根治標籤溢出撐爆的問題。
- **滑動更新動畫**：在 `page.tsx` 中實作 CSS 滑動動畫過渡。當 7 秒定時器觸發有新玩家加入時，最左側名片會從左邊以 `slideInLeft` 流暢滑入，並將舊名片平滑向右推動，最舊名片從右側滑出剔除，營造流滑的「河道更新」質感。
