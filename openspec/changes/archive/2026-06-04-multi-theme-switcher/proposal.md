## Why

為符合 **AFTER MIDNIGHT** 品牌「現代、精緻、具備物理層次感」的新視覺調性，我們需要一個高度可擴充的風格與配色切換系統。由於團隊與使用者目前對風格配色「飄浮不定」，建立一個可在網頁上隨時切換多套明亮版風格主題（如藍莓優格、森系香草紙片浮雕、極簡畫廊等）的切換器，能最直觀地幫助團隊在瀏覽器上實測、比對並進行最終風格決策。同時，這也為未來依據定案明亮版所演繹的夜間版切換打下基礎。

## What Changes

- **新增多主題語義變數**：在 CSS 中宣告一套動態的主題語義變數（如背景、主色、次要、點綴、投影等），並透過 HTML class 載入不同風格。
- **重構 TopBar 右上角切換按鈕**：將原本簡單的月亮切換按鈕重構為可展開的「主題選單」，使用者能在此勾選不同的明亮版風格主題（如藍莓優格、森系香草紙雕等），或一鍵切換至夜間版。
- **儲存主題狀態**：利用 `localStorage` 記憶使用者選定的主題與風格，並同步在 Next.js 的客戶端渲染中，避免畫面跳閃。
- **極佳的擴充性**：主題切換架構設計保持高度可擴充性，未來可透過 CSS 變數直接新增、擴充或實驗新的配色與風格主題，不影響現有代碼結構。

## Capabilities

### New Capabilities
- `multi-theme-switcher`: 實作一個高度可擴充的多套明亮版風格與配色切換器，支援在網頁上無縫切換多種實驗主題（如藍莓優格、森系香草等），並保留未來切換至對應夜間版的接口。

### Modified Capabilities
*(無)*

## Impact

- **CSS 配置**：`globals.css` 中需要擴充多個風格的主題 CSS 變數與 Tailwind CSS v4 主題宣告。
- **UI 元件**：修改 `TopBar.tsx` 的月亮按鈕為可展開的主題面板。
- **全站元件配色**：將主要頁面與元件中 hardcode 的莫蘭迪/禪意色調，更換為動態的主題語義變數。
