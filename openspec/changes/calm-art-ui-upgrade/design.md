## Context

當前 OW Social 網站使用 Next.js 16 (React 19) 與 Tailwind CSS v4 進行開發。系統本身已經完整實作了莫蘭迪暖灰沙色系（Style A/B/AB 主題），並註冊了豐富的主題色彩變數（如 `--theme-accent`, `--theme-highlight`, `--theme-bg-gradient`）。
然而，現有卡片、首頁 Hero、進度圖表與背景仍帶有偏光科技感與精準度（例如 Cyber-dots 剛硬點矩陣、 macOS 魚眼科技導航、旋轉全息雷達等）。
為了解決此美學落差，本設計旨在不改動現有功能與配色色彩架構的前提下，利用 CSS 噪點濾鏡、物理多重軟陰影、不規則有機圓角以及 SVG 禪意裝飾曲線，將視覺全面升級為溫柔安靜的 **Calm Premium Art-UI**，並在獨立預覽分支上進行安全試做。

## Goals / Non-Goals

**Goals:**
*   **物理手作顆粒紙感**: 在全站最上層疊加超輕量內聯 SVG 噪點，使整個介面具備日本和紙或手工水彩紙的磨砂溫潤感。
*   **有機溫潤大圓角與多層陰影**: 卡片圓角全面大於 32px，並使用多層擴散的極低飽和軟陰影，配合頂部高光，創造卡片輕柔漂浮於紙上的空氣感。
*   **禪意流體與雲霧背景**: 建立全新的 `ArtOrnament` 背景裝飾層，渲染 2 條超淡貝茲曲線、1 組禪意同心圓，以及 3 個帶有極慢呼吸動畫的大模糊度雲霧斑塊。
*   **首頁 Hero 與圖表藝術重構**: 重構首頁 Hero 區塊的偏光雷達為「水面微瀾禪意圓」，並重寫 Tasks Overview 的圓環為手繪筆刷水彩進度環。
*   **導航列鵝卵石化與水彩渲染**: 優化 `FloatingDock` 與按鈕，換成溫順的「水滴微膨脹與水彩暈染」互動。
*   **完美保留色彩與功能**: 所有的美學升級必須在不改動任何現有色系配色與網站功能的條件下實施。

**Non-Goals:**
*   不變更任何現有色彩（保留 Style A/B/AB 主題配色）。
*   不改動任何資料庫結構、Supabase 設定與 API 串接邏輯。
*   不修改任何網站的現有功能與資訊架構。

## Decisions

*   **1. 噪點紙張質感 (Paper-like Texture)**:
    *   **選擇**: 採用內聯 SVG base64 噪點，透過 CSS 的 `body::before` 以 fixed 定位與 `pointer-events-none` 鋪設於全站最頂層（z-index 999），且不透明度控制在極低微的 0.015。
    *   ** rationale**: 此方法不需要額外的 HTTP 圖片請求，載入極快，且噪點覆蓋在最上層能讓所有的卡片與背景都蒙上一層微顆粒感，在不影響原有色彩的前提下大幅提升觸覺高級感。
*   **2. 背景雲霧 (Misty Layers)**:
    *   **選擇**: 在底層渲染 3 個純色斑塊，套用極大模糊度 (`blur-[120px] ~ blur-[140px]`) 與大半透明度（`0.12 ~ 0.2`），配合 CSS Keyframes Transform 進行極慢速的漂流與縮放動畫。
    *   ** rationale**: 完全避開了圖片資源，使用純 CSS 實作，效能高，並能直接抓取你當前色系的 `--theme-accent-rgb` 變數，讓雲霧色彩與原站色系渾然一體。
*   **3. 流體線條與禪意圓弧 (Zen Ornaments)**:
    *   **選擇**: 建立一個獨立的 React 背景裝飾元件 `ArtOrnament.tsx`，在其中直接 Inline 渲染高精細度貝茲曲線與禪意同心圓，其 `strokeWidth` 與 `opacity` 控制在極淡的範圍。
    *   ** rationale**: 對於幾何精細度要求極高的流動線條與虛線同心圓，SVG 向量最為合適，且能與 React 組件結構完美整合，維護極其清晰。
*   **4. 大圓角與物理陰影**:
    *   **選擇**: 直接透過 CSS 新增 `.glass-panel` 與 `.organic-corners` 樣式，並設定物理多重擴散軟陰影。
    *   ** rationale**: 這樣做可以直接沿用現有的 DOM 結構，完全不需要改動 Next.js 頁面元件的架構，極易套用與維護。

## Risks / Trade-offs

*   **[Risk] 大模糊度 (blur-120px) 與噪點濾鏡可能在低配電腦或行動裝置上引發渲染重繪效能瓶頸。**
    *   -> [Mitigation] 雲霧斑塊控制在 3 個以內，且呼吸動畫的時間設定得極長（22s 至 28s 之間），並使用支援 GPU 加速的 `transform` 屬性而非 `top/left` 來進行微小移動。噪點濾鏡使用 fixed pointer-events-none，防止引發滾動時的重繪，從而穩定保持 60fps。
*   **[Risk] 噪點濾鏡可能導致文字邊緣模糊，降低閱讀性。**
    *   -> [Mitigation] 噪點不透明度嚴格控制在 `0.015` 以內，文字依然享有高對比度的優雅墨色，不影響任何高傳真閱讀體驗。
