# After Midnight — 網站圖片模糊問題與 SEO 關鍵字優化診斷報告

> **診斷日期**：2026-06-11
> **適用專案**：After Midnight 玩家名片展示館 (Next.js & Vercel 部署)
> **目的**：解決玩家名片與頭像在不同設備間歇性模糊的問題，並將圖片的 `alt` 屬性統一優化為「鬥陣特攻」繁體中文關鍵字。

---

## 🔍 問題描述與現象
在網站運行過程中，有時會觀察到以下現象：
1. **間歇性模糊**：同一個網頁，有時候打開圖片是清晰的，有時候卻是模糊的（通常在第一次載入時模糊，重新整理後變清晰）。
2. **跨設備差異**：在一般桌上型電腦螢幕上看很正常，但在 **iPhone、iPad 或高階 Android 手機**上觀看時，圖片邊緣有明顯的模糊或顆粒感。

---

## 🛠️ 兩大技術主因分析

### 原因一：Retina/行動裝置螢幕的「設備像素比 (DPR)」適配問題
現代智慧型手機與高階螢幕（如 Apple Retina 顯示器）的物理像素密度非常高。

* **運作機制**：
  * **一般電腦螢幕 (DPR = 1)**：在網頁上顯示 `150px` 寬度的圖片，剛好填滿螢幕的 150 個物理像素點，看起來清晰。
  * **手機/Retina 螢幕 (DPR = 2 ~ 3)**：在畫面上雖然也是 `150px` 寬，但因為螢幕密度極高，瀏覽器實際上需要 `300px` 甚至 `450px` 的圖片解析度才能填滿物理像素。如果回傳的圖片剛好是 150px，瀏覽器被迫將其**拉大 2-3 倍**渲染，就會看起來非常模糊。
* **診斷結論**：當前專案部分圖片（如頭像或卡片立繪）因為沒有針對 DPR 提供倍數圖源，導致在手機端觀看時產生間歇性模糊。

---

### 原因二：Vercel / Next.js 圖片優化快取延遲 (Image Cache Processing)
當您第一次訪問新網頁、或快取過期時，會觸發 Next.js 的動態圖片處理機制：

1. **快取未命中 (Cache Miss)**：
   第一位訪客進來時，Vercel 伺服器需要在背景下載原圖並進行 WebP 壓縮與重設尺寸。為了防止網頁加載被卡住，Next.js 會先回傳一個低解析度的臨時圖（Blur Placeholder）或縮圖，此時訪客會看到**模糊的圖片**。
2. **快取命中 (Cache Hit)**：
   一旦伺服器背景處理完成，高畫質 WebP 就會被快取在 Vercel Edge CDN。此後所有訪客（或是重新整理網頁）就能瞬間拿到高畫質 WebP，圖片**回復清晰**。

## ✍️ SEO 關鍵字優化提案 (使用「鬥陣特攻」繁體中文)
Google 爬蟲無法直接解讀圖片內容，必須依賴 `alt` 屬性。我們建議將原本僅顯示英文/中文名字的 `alt` 屬性，全面升級為融入**「鬥陣特攻」**關鍵字的繁體中文結構：

### 1. 玩家名片上的英雄全身立繪
修改檔案：`src/components/OWCard.tsx`
* **修改前**：
  ```tsx
  <img src={`/images/heroes/full/${heroInfo.id}.png`} alt={heroInfo.name} />
  ```
* **修改後**（融入繁體關鍵字）：
  ```tsx
  <img src={`/images/heroes/full/${heroInfo.id}.png`} alt={`《鬥陣特攻》英雄 ${heroInfo.name} 角色名片立繪`} />
  ```

### 2. 動態玩家頁面的大頭貼區
修改檔案：`src/app/player/[id]/page.tsx`
* **修改前**：
  ```tsx
  <img src={`/images/heroes/avatars/${hero.id}.png`} alt={hero.name} />
  ```
* **修改後**：
  ```tsx
  <img src={`/images/heroes/avatars/${hero.id}.png`} alt={`《鬥陣特攻》英雄 ${hero.name} 大頭貼`} />
  ```

## 💡 具體技術排查與解決方案建議

1. **為行動裝置調整 `sizes` 屬性 (針對使用 `next/image` 的地方)**：
   在 `<Image>` 元件中明確給予 sizes 屬性，例如：
   ```tsx
   sizes="(max-width: 768px) 100vw, (max-width: 1200px) 50vw, 33vw"
   ```
   這能引導 Next.js 根據訪客設備的螢幕解析度（DPR）自動回傳 2 倍或 3 倍大小的優化圖片。
2. **調高圖片壓縮品質**：
   Next.js 預設的圖片優化品質是 `75`。對於遊戲卡片等有細緻立繪的網站，建議將 quality 調高至 `85` 或 `90`，以防止細節被過度壓縮產生糊邊：
   ```tsx
   quality={85}
   ```
3. **限制上傳來源圖片解析度**：
   對於玩家自己上傳頭貼的功能，限制其上傳的圖片解析度不得低於 `400x400` 像素，並在後端裁切為適當的大小。
