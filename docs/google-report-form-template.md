# After Midnight Google 表單欄位模板

## 表單基本設定

| 項目 | 建議設定 |
| --- | --- |
| 表單標題 | After Midnight Beta 回報表單 |
| 表單說明 | 請用這份表單回報錯誤、不當名片、資料刪除請求、建議或聯絡我們。若需要站方回覆，請留下可聯絡方式。請不要送出你不想讓站方看到的私人資訊。 |
| 收集電子郵件地址 | 建議關閉，改用下方「聯絡方式」欄位，讓玩家自行選擇 Email 或 Discord。 |
| 限制為同一組織使用者 | 關閉 |
| 允許編輯回覆 | 關閉 |
| 檔案上傳 | 第一版不建議開啟，先請玩家貼截圖或影片連結。 |

## 欄位設定

| 順序 | 欄位名稱 | 類型 | 必填 | 選項或提示文字 |
| --- | --- | --- | --- | --- |
| 1 | 回報類型 | 單選 | 是 | 錯誤回報 / 不當名片 / 資料刪除請求 / 提供建議 & 聯絡我們 |
| 2 | 聯絡方式 | 簡答 | 否 | 若需要回覆，請填 Email 或 Discord，例如 `aftermidnight.halo@gmail.com` 或 `name#0000`。 |
| 3 | 發生問題的頁面 | 單選 | 否 | 首頁 / 展示館 / 工作室 / 玩家名片頁 / 分享頁 / 其他 |
| 4 | 問題或建議描述 | 段落 | 是 | 請描述你看到什麼、按了什麼、預期應該發生什麼。 |
| 5 | 重現步驟 | 段落 | 否 | 例如：進入展示館 > 點某張名片 > 手機畫面被裁切。 |
| 6 | 截圖或影片連結 | 簡答 | 否 | 可貼 Google Drive、YouTube、Imgur、Discord 圖片連結。 |
| 7 | 裝置類型 | 單選 | 否 | 手機 / 平板 / 電腦 / 不確定 |
| 8 | 瀏覽器 | 單選 | 否 | Chrome / Safari / Edge / Firefox / 其他 / 不確定 |
| 9 | 是否同意站方為處理此回報而查看你提供的內容 | 核取方塊 | 是 | 我同意 After Midnight 只為處理本次回報查看我提供的內容與聯絡方式。 |

## 回覆流程建議

| 狀態 | 建議處理方式 |
| --- | --- |
| 收到錯誤回報 | 先回覆「已收到，會確認」，需要更多資料時再請對方補截圖或影片。 |
| 收到不當名片回報 | 先確認被回報的名片頁連結或玩家名稱，再決定是否隱藏或要求修正。 |
| 收到資料刪除請求 | 先確認對方身份與要刪除的資料，再處理刪除。 |
| 收到建議或聯絡 | 回覆感謝與是否會納入 Beta 待辦，不承諾一定會做。 |
